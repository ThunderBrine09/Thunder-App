# Master Data Management App

A React + Vite + Tailwind app for managing daily operations including Orders, Sales, Purchases, Consumption, and Wastage. Supports centralized master data management.

---

## ✅ Requirements

Before you run this app, ensure the following are installed on your system:

- **Node.js (v18 or higher)** – https://nodejs.org
- **npm** (comes with Node.js)
- **Code editor** (VS Code recommended) – https://code.visualstudio.com

---

## 📦 Tech Stack

- React (UI Framework)
- Vite (Development Tool)
- Tailwind CSS (Styling)
- shadcn/ui (Prebuilt UI Components)
- lucide-react (Icons)
- date-fns (Date Utilities)
- classnames (Utility library)
